* MIDI-Hex Reference

** Syntax

- =#= Line comment
- =<= Playback skip
- =>= Playback resume
- === Major row highlight
- =-= Minor row highlight

** Events

- =T iiif= Tempo (12.4 bit BPM)
- =S ttrr= Delay Ticks + Repeat
- =M cm00= Set Column MIDI Channel + Mute State
- =C bbpp= Program Change
- =K kkvv= Note On
- =R kkvv= Note Off
- =N kkvv= Prev Note Off + Note On
- =L kkvv= Note On + Prev Note Off ("Legato")
- =A kkpp= Key Pressure (key = =80= for channel pressure)
- =B ccvv= Control/RPN Change
- =E vvvv= Pitch Wheel

*** Controllers

- =B 01vv= Modulation (Vibrato)
- =B 07vv= Channel Volume
- =B 0Avv= Channel Panning
- =B 0Bvv= Expression
- =B 7800= All Sound Off
- =B 7900= Reset All Controllers
- =B 7B00= All Notes Off
- =B 80vv= Pitch Bend Range
- =B 81vv= Fine Tune
- =B 82vv= Coarse Tune

** Meta Commands

- =tpqn= Ticks Per Quarter Note (must be first)
- =mode= MIDI Mode / Reset (GM, GM2, GS, XG)
- =stop= End of Track (must be last)
- =sysx= Raw SysEx bytes
- =soff= All Sound Off

Text:
- =text= Text Event
- =copy= Copyright / Artist
- =trck= Track Name
- =inst= Instrument / Synth / Soundfont
- =lyrc= Lyric
- =mark= Marker
- =cuep= Cue Point

*** SysEx Messages

- =41 10 42 12 40 1A 15 01 10= Setup second drum channel =A= (requires GS mode)
